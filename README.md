# AI/CS Portfolio for GitHub Pages

GitHub Pages로 배포할 수 있는 개인 CV/Resume 기반 포트폴리오 템플릿입니다.

## 제출 링크 형식

- GitHub Repository URL: `https://github.com/username/portfolio`
- GitHub Pages 배포 URL: `https://username.github.io/portfolio`
- 사용자 계정 페이지인 경우: `https://username.github.io`

## 수정해야 할 항목

`index.html`에서 `[Your Name]`, `[전공]`, `[관심 분야]`, `[프로젝트명]`, `student@example.com`, `https://github.com/username` 등 대괄호로 표시된 내용을 본인 정보로 교체하세요.

증명사진은 `assets/profile-placeholder.png`를 본인 사진 파일로 교체하면 됩니다. 파일명을 그대로 유지하면 HTML 수정 없이 바로 반영됩니다.

`resume.pdf`는 현재 제출 전 교체용 placeholder입니다. 최종 제출 전 본인의 이력서 PDF로 바꾸되, 주민등록번호, 상세 주소, 전화번호 등 민감한 개인정보를 포함하지 마세요.

## GitHub Pages 배포 방법

1. GitHub에서 `portfolio` 저장소를 생성합니다.
2. 이 폴더의 파일을 저장소 루트에 업로드합니다.
3. 저장소의 `Settings` → `Pages`로 이동합니다.
4. `Build and deployment`에서 `Deploy from a branch`를 선택합니다.
5. Branch를 `main`, folder를 `/root`로 선택한 뒤 저장합니다.
6. 잠시 후 `https://username.github.io/portfolio` 주소로 접속합니다.

## 레퍼런스에서 반영한 구성

- 첫 화면에서 이름, 전공, 관심 분야, 이력서 링크를 바로 보여줍니다.
- 프로젝트는 요약, 기간, 기술 스택, 역할, 주요 기능, 결과, GitHub 링크를 한 카드 안에 정리합니다.
- Skills는 분야별로 나누고 숙련도 표시를 추가했습니다.
- Education, Experience, Contact, Career Goal을 과제 요구 순서에 맞춰 구성했습니다.
